Read GitHub in your own language.

Aspid.Translator.GitHub translates pull requests, issues, discussions, releases, commits and documentation right on github.com. The translation appears where the original was. Code, links and mentions stay as they are, and the original is one click away.

Free and private: translation runs on your device with Chrome's built-in translator. No account, no API key, no servers.

WHAT GETS TRANSLATED
• Pull requests: titles, descriptions, conversation and code review comments
• Issues and Discussions: titles, bodies, answers and replies
• PR and issue lists, releases and release notes, Compare commit messages and Wiki pages
• Commits: titles and descriptions in lists, on commit pages and in timelines
• Repository READMEs, rendered .md files, About descriptions and file-list commit messages
• Content cards on signed-in Home and Feed pages

CODE STAYS CODE
Code blocks, inline code, identifiers such as SerializeReference, @mentions, #issue references, links, conventional commit prefixes (fix(scope):) and git trailers (Co-Authored-By:) are preserved. Source diffs, comment editors, release versions and download names stay unchanged.

THE ORIGINAL IS ONE CLICK AWAY
• Comments, documents and release notes have their own translation controls
• Titles show the original on hover
• Lists, Wiki, Home and Feed use the page-wide control
• Use the floating button or keyboard shortcut to switch the whole page

TRANSLATES AS YOU SCROLL
Only content near the viewport is translated. Text already in your language is skipped. New and edited comments and page switches without a reload are picked up automatically.

YOUR RULES
• Choose from 39 target languages, including English, Russian, Ukrainian, Arabic, Chinese (Simplified and Traditional), French, German, Japanese and Korean
• The target follows your browser's preferred languages until you choose another
• The settings page is available in every target language
• Translate automatically or on demand, and choose which parts of GitHub to translate

PRIVACY
• Text is processed by Chrome on your device and is not sent to a translation server.
• Chrome downloads language models from Google when needed. Your page text is not included in those download requests.
• The extension runs only on github.com and requests storage to keep your settings locally.
• No analytics, tracking or extension account.
• Nothing is posted to GitHub. Other people continue to see the original.

REQUIREMENTS
Desktop Google Chrome 138 or newer. On first use, click Download translation model when prompted. Initial model downloads need an internet connection. Language-pair availability depends on Chrome.
