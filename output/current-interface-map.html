Настройки

Отдельная вкладка

Изменения сохраняются сразу и применяются в открытых вкладках GitHub.

По умолчанию язык берётся из предпочтений браузера. Язык интерфейса настроек следует языку перевода.

Настройки следуют светлой / тёмной теме системы; элементы на GitHub используют тему GitHub.

Состояния существующих элементов

Кнопка справа снизу

Ручной режим → «Перевести»
Первый запуск пары языков → «Скачать модель перевода»
Загрузка → «Загрузка модели N%»
Обработка → «Перевожу… (N)»
Готово → «Показать оригинал» ⇄ «Показать перевод»

Строка над текстовым блоком

Обработка → «Перевожу…»
Нужна модель → «Скачать»
Перевод ⇄ оригинал → языки + действие
Ошибка перевода → причина + «Повторить»
Ошибка скачивания → причина

Переключатель над блоком действует только на этот блок; плавающая кнопка — на все переводы страницы.

Код, ссылки, упоминания и номера задач сохраняются. Если текст пропущен или не изменился, строка перевода не показывается.
