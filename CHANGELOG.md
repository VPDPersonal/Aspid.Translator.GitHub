# Changelog

## 0.1.0 (unreleased)

Initial public release candidate for desktop Google Chrome 138 or newer.

- Translate pull requests, review comments, issues, Discussions, releases and commit messages in place.
- Translate PR and issue lists, Compare commit messages, Wiki, rendered Markdown, repository About and Home/Feed content cards.
- Choose from 39 target languages and localized settings pages.
- Switch between translations and originals globally or for individual content groups.
- Preserve code, links, mentions, conventional commit prefixes, git trailers and document anchors.
- Use Chrome's on-device translation and language detection, with a local extension detector fallback.
- Keep settings locally, without analytics, accounts or a translation server.

The public store URL and release date will be added after approval and installation verification.
